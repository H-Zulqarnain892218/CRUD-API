# CRUD API - Flyrank Internship Assignment

A simple, lightweight in-memory REST API built with FastAPI to handle tasks. Developed as part of the backend engineering evaluation tasks.

## Features
* Clean routing for root and health checks.
* Full CRUD (Create, Read, Update, Delete) operations for tasks.
* Automated interactive documentation using Swagger UI.
* Input validation handled securely through Pydantic.

## Tech Stack
* Python
* FastAPI
* Uvicorn
* Pydantic
